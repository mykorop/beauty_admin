# 27: Детальна статистика: топи, якість, «Потребують уваги»

**What to build:** Детальна статистика доповнюється топами, блоком якості та списком «Потребують уваги».

**Blocked by:** 26 (Детальна статистика: рушій + ріст, Записи, Вартість Записів); 22 (Модерація відгуків)

**Status:** ready-for-human

Специфікація: `../spec.md` · Словник: `CONTEXT.md` · ADR: `docs/adr/`. Тикет зачіпає обидва репозиторії (`bookme-backend` → `admin-api`, `beauty_admin` → UI), якщо не сказано інше.

- [x] Топ-10 Салонів, Незалежних майстрів і міст за кількістю Записів за останні 30 днів; Видалені й Заблоковані в топи не потрапляють
- [x] Якість: нові відгуки, середній рейтинг і відгуки з оцінкою ≤ 2 за останні 7 днів; приховані відгуки не враховуються; перехід у стрічку модерації
- [x] «Потребують уваги» з п'ятьма незалежними фільтрами: без Записів за 30 днів; без послуг; без Годин роботи чи Робочого графіка; незавершений профіль старший за 7 днів; Майстри салону у Видаленому Салоні
- [x] Кожен рядок веде в картку профілю; для застряглих Майстрів — у Ростер, де доступне вилучення
- [x] Юніт-тести модуля агрегації на кожну ознаку й межі періодів; Playwright
