# 22: Модерація відгуків

**What to build:** Адміністратор платформи переглядає стрічку відгуків платформи й вкладку «Відгуки» в картках, приховує відгук із причиною або повертає його; рейтинг профілів перераховується.

**Blocked by:** 06 (Редагування профілю Салону + Журнал дій)

**Status:** ready-for-agent

Специфікація: `../spec.md` · Словник: `CONTEXT.md` · ADR: `docs/adr/`. Тикет зачіпає обидва репозиторії (`bookme-backend` → `admin-api`, `beauty_admin` → UI), якщо не сказано інше.

- [ ] `GET /admin/reviews` (обов'язковий діапазон дат або сутність, без Scan), `POST /admin/reviews/{id}/hide`, `…/unhide`
- [ ] Фільтри: оцінка, дата, Салон, Майстер, стан (видимий / прихований)
- [ ] Відгук отримує час і причину приховання; прихований зникає з усіх клієнтських стрічок
- [ ] Рейтинг і кількість відгуків Салону й Майстра перераховуються з нуля з видимих відгуків, з оптимістичним блокуванням за лічильником; результат ніколи не `NaN`, зокрема коли видимих відгуків не лишилось
- [ ] Lock «один відгук на Запис» не звільняється: новий відгук на той самий Запис неможливий
- [ ] Текст і оцінку змінити неможливо — ендпоінта не існує
- [ ] Новий тип сповіщення Власнику салону / Майстру про приховання
- [ ] Рядок Журналу дій із причиною
- [ ] Jest: перерахунок при приховані й поверненні, останній відгук, lock; Playwright
