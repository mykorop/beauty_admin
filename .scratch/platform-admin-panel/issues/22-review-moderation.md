# 22: Модерація відгуків

**What to build:** Адміністратор платформи переглядає стрічку відгуків платформи й вкладку «Відгуки» в картках, приховує відгук із причиною або повертає його; рейтинг профілів перераховується.

**Blocked by:** 06 (Редагування профілю Салону + Журнал дій)

**Status:** ready-for-human

Специфікація: `../spec.md` · Словник: `CONTEXT.md` · ADR: `docs/adr/`. Тикет зачіпає обидва репозиторії (`bookme-backend` → `admin-api`, `beauty_admin` → UI), якщо не сказано інше.

- [x] `GET /admin/reviews` (обов'язковий діапазон дат або сутність, без Scan), `POST /admin/reviews/{id}/hide`, `…/unhide`
- [x] Фільтри: оцінка, дата, Салон, Майстер, стан (видимий / прихований)
- [x] Відгук отримує час і причину приховання; прихований зникає з усіх клієнтських стрічок
- [x] Рейтинг і кількість відгуків Салону й Майстра перераховуються з нуля з видимих відгуків, з оптимістичним блокуванням за лічильником; результат ніколи не `NaN`, зокрема коли видимих відгуків не лишилось
- [x] Lock «один відгук на Запис» не звільняється: новий відгук на той самий Запис неможливий
- [x] Текст і оцінку змінити неможливо — ендпоінта не існує
- [x] Новий тип сповіщення Власнику салону / Майстру про приховання
- [x] Рядок Журналу дій із причиною
- [x] Jest: перерахунок при приховані й поверненні, останній відгук, lock; Playwright
