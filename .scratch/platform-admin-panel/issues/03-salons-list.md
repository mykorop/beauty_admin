# 03: Список Салонів

**What to build:** Адміністратор платформи відкриває «Салони» й бачить таблицю всіх Салонів платформи з пошуком, фільтрами й сортуванням.

**Blocked by:** 02 (Вхід з MFA й оболонка адмінки)

**Status:** ready-for-agent

Специфікація: `../spec.md` · Словник: `CONTEXT.md` · ADR: `docs/adr/`. Тикет зачіпає обидва репозиторії (`bookme-backend` → `admin-api`, `beauty_admin` → UI), якщо не сказано інше.

- [ ] `GET /admin/salons` будує список Scan-ом рядків профілів Салонів із проєкцією лише полів таблиці (ADR-0002), кешує на кілька хвилин, повертає час побудови; параметр примусового оновлення обходить кеш
- [ ] Колонки: назва, місто, Власник салону, рейтинг, кількість відгуків, стан (активний / Заблокований / Видалений), дата реєстрації
- [ ] Пошук за назвою, email-ом, телефоном; фільтри за станом і містом; сортування за будь-якою колонкою; пагінація — усе в браузері
- [ ] Видалені Салони приховані за замовчуванням і з'являються лише за явним фільтром, із виразною позначкою
- [ ] Стан таблиці живе в query-параметрах адреси й відновлюється при відкритті посилання
- [ ] Видно «оновлено о …» і кнопку «Оновити»
- [ ] Клік по рядку веде на адресу картки Салону
- [ ] Jest: роль, форма відповіді, кеш і його обхід; Playwright: пошук, фільтри, сортування, стан в адресі
