# 24: Клієнти

**What to build:** Адміністратор платформи шукає Клієнта, відкриває його картку з Записами й відгуками та може Заблокувати його.

**Blocked by:** 19 (Записи в картці: список і деталі); 18 (Блокування Салону й Майстра)

**Status:** ready-for-agent

Специфікація: `../spec.md` · Словник: `CONTEXT.md` · ADR: `docs/adr/`. Тикет зачіпає обидва репозиторії (`bookme-backend` → `admin-api`, `beauty_admin` → UI), якщо не сказано інше.

- [ ] `GET /admin/clients` (Scan + кеш), `GET /admin/clients/{clientId}`, `GET …/appointments`, `GET …/reviews`, `POST …/block`, `…/unblock`
- [ ] Таблиця з пошуком за іменем, email-ом, телефоном і фільтром за станом
- [ ] Картка: профіль лише на читання, історія Записів, залишені відгуки, Історія
- [ ] Блокування з причиною: Клієнт входить і бачить свої Записи, але створення Запису відхиляється новим стабільним кодом помилки; наявні Записи чинні
- [ ] Відповідь профілю client-api несе стан Блокування
- [ ] Редагувати профіль Клієнта неможливо — ендпоінта не існує
- [ ] Рядок Журналу дій
- [ ] Jest + Playwright
