# 21: Масове скасування майбутніх Записів

**What to build:** Адміністратор платформи бачить попередження «N майбутніх Записів» на картці Видаленого чи Заблокованого профілю та в діалозі Блокування, і скасовує їх усі однією дією з однією причиною.

**Blocked by:** 20 (Дії над Записом); 18 (Блокування Салону й Майстра)

**Status:** ready-for-agent

Специфікація: `../spec.md` · Словник: `CONTEXT.md` · ADR: `docs/adr/`. Тикет зачіпає обидва репозиторії (`bookme-backend` → `admin-api`, `beauty_admin` → UI), якщо не сказано інше.

- [ ] `GET …/appointments/upcoming-count` і `POST …/appointments/cancel-upcoming` для Салону й Майстра
- [ ] Скасовуються всі майбутні Записи зі статусом «заброньовано»; слот-lock-и звільняються; кожен Клієнт отримує звичайне сповіщення
- [ ] Один рядок Журналу дій з переліком зачеплених Записів
- [ ] Операція ідемпотентна й повертає, скільки скасовано й скільки не вдалося
- [ ] Дозволена над Видаленим профілем — другий виняток із заборони записувальних дій
- [ ] Діалог Блокування показує N і пропонує масове скасування окремим свідомим кроком; саме Блокування нічого не скасовує
- [ ] Jest: часткова невдача, повторний запуск, Видалений Салон; Playwright
