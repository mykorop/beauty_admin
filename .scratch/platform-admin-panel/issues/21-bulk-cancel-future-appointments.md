# 21: Масове скасування майбутніх Записів

**What to build:** Адміністратор платформи бачить попередження «N майбутніх Записів» на картці Видаленого чи Заблокованого профілю та в діалозі Блокування, і скасовує їх усі однією дією з однією причиною.

**Blocked by:** 20 (Дії над Записом); 18 (Блокування Салону й Майстра)

**Status:** ready-for-human

Специфікація: `../spec.md` · Словник: `CONTEXT.md` · ADR: `docs/adr/`. Тикет зачіпає обидва репозиторії (`bookme-backend` → `admin-api`, `beauty_admin` → UI), якщо не сказано інше.

- [x] `GET …/appointments/upcoming-count` і `POST …/appointments/cancel-upcoming` для Салону й Майстра
- [x] Скасовуються всі майбутні Записи зі статусом «заброньовано»; слот-lock-и звільняються; кожен Клієнт отримує звичайне сповіщення
- [x] Один рядок Журналу дій з переліком зачеплених Записів
- [x] Операція ідемпотентна й повертає, скільки скасовано й скільки не вдалося
- [x] Дозволена над Видаленим профілем — другий виняток із заборони записувальних дій
- [x] Діалог Блокування показує N і пропонує масове скасування окремим свідомим кроком; саме Блокування нічого не скасовує
- [x] Jest: часткова невдача, повторний запуск, Видалений Салон; Playwright
