# 04: Картка Салону: перегляд

**What to build:** Адміністратор платформи відкриває Салон і бачить картку з вкладками; Профіль і Години роботи доступні на читання. Це каркас, який наповнюють усі наступні тикети.

**Blocked by:** 03 (Список Салонів)

**Status:** ready-for-agent

Специфікація: `../spec.md` · Словник: `CONTEXT.md` · ADR: `docs/adr/`. Тикет зачіпає обидва репозиторії (`bookme-backend` → `admin-api`, `beauty_admin` → UI), якщо не сказано інше.

- [ ] `GET /admin/salons/{salonId}` повертає повний профіль, включно зі станом Блокування й видалення та коротким посиланням; `GET …/hours` — Години роботи по днях тижня
- [ ] Перевикористовуваний компонент картки профілю, який отримує набір вкладок ззовні (його ж використає Незалежний майстер)
- [ ] Вкладки: Профіль · Години роботи · Ростер · Каталог послуг · Записи · Відгуки · Фото й сертифікати · Інвайти · Історія; кожна має власну адресу; ще не реалізовані — заглушки
- [ ] Профіль показує всі поля зі специфікації; дати й час — у часовому поясі закладу, не браузера
- [ ] Видалений Салон відкривається на читання з виразною позначкою
- [ ] Неіснуючий `salonId` → 404 з перекладеним повідомленням
- [ ] Jest + Playwright покривають перегляд активного й Видаленого Салону та 404
