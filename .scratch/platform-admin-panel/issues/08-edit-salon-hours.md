# 08: Редагування Годин роботи

**What to build:** Адміністратор платформи змінює Години роботи Салону по днях тижня.

**Blocked by:** 06 (Редагування профілю Салону + Журнал дій)

**Status:** ready-for-agent

Специфікація: `../spec.md` · Словник: `CONTEXT.md` · ADR: `docs/adr/`. Тикет зачіпає обидва репозиторії (`bookme-backend` → `admin-api`, `beauty_admin` → UI), якщо не сказано інше.

- [ ] `PUT /admin/salons/{salonId}/hours` — та сама схема й сервіс, що salon-api

- [ ] Jest на кожну відмову й успіх; Playwright на редагування й відображення відмови
