# 09: Ростер і картка Майстра салону

**What to build:** Адміністратор платформи бачить Ростер Салону й Інвайти, відкриває Майстра салону зсередини Ростеру й редагує дані його лінку.

**Blocked by:** 06 (Редагування профілю Салону + Журнал дій)

**Status:** ready-for-agent

Специфікація: `../spec.md` · Словник: `CONTEXT.md` · ADR: `docs/adr/`. Тикет зачіпає обидва репозиторії (`bookme-backend` → `admin-api`, `beauty_admin` → UI), якщо не сказано інше.

- [ ] `GET /admin/salons/{salonId}/masters`, `GET …/masters/{masterId}`, `PATCH …/masters/{masterId}`, `GET …/invites`
- [ ] Ростер: ім'я, аватар, спеціалізація, статус лінку, комісія, рейтинг, дата приєднання, позначка Власника-майстра
- [ ] Картка Майстра салону відкривається з Ростеру, має вкладки Профіль · Робочий графік · Копії послуг · Записи · Відгуки (нереалізовані — заглушки) з власними адресами
- [ ] Редагуються спеціалізація, комісія, горизонт бронювання; цим PATCH-ем не можна ні почати, ні закінчити співпрацю
- [ ] Вкладка «Інвайти» — лише читання: статус, email, строк дії
- [ ] Способу додати Майстра в Ростер повз Інвайт не існує ні в API, ні в UI
- [ ] Зміни пишуться в Журнал дій із контекстним Салоном
- [ ] Jest + Playwright
